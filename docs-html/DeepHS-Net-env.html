项目简介

DeepHS-Fruit 是德国图宾根大学认知系统实验室开发的高光谱水果成熟度检测系统。该项目利用深度学习技术（HS-CNN）处理高光谱成像数据，能够非破坏性地检测水果的成熟度、硬度和糖度，在5种水果上达到了85%以上的分类准确率。

核心特性

特性 详细说明
多种水果支持 牛油果（Avocado）、猕猴桃（Kiwi）、柿子（Kaki）、芒果（Mango）、木瓜（Papaya）
多相机数据 Specim FX10（可见光）、INNO-SPEC RedEye 1.7（近红外）、Corning microHSI 410（混合）
多维度标签 成熟度等级（Ripeness Level 1-5）、硬度（Firmness, N）、糖度（Sugar Content, °Brix）
SOTA性能 成熟度分类准确率 85-90%，硬度预测 R²>0.88，糖度预测 R²>0.82
开源数据 143GB 完整数据集，包含数千个高光谱图像样本
论文来源：
Varga, L. A., Makowski, J., & Zell, A. (2021). "Measuring the Ripeness of Fruit with Hyperspectral Imaging and Deep Learning". In 2021 International Joint Conference on Neural Networks (IJCNN).

方案A：CUDA 12.x（RTX 40系列推荐）

方案B：CUDA 11.8（RTX 30系列、GTX 16系列）

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

方案C：CPU版本（无GPU或集成显卡）

- 文件大小：约2-3GB

可能的原因和解决方案：
1. 安装了CPU版本的PyTorch → 卸载重装GPU版本
2. CUDA驱动版本不匹配 → 更新显卡驱动
3. 显卡不支持CUDA → 只能使用CPU训练

验证方案：

12 设置环境变量

配置PYTHONPATH环境变量，使Python能够找到项目中的所有模块。

执行命令

# 进入代码根目录 cd E:\DeepHS-Fruit\deephs_fruit # 激活虚拟环境（如果还没激活） conda activate hyperspectral # 设置PYTHONPATH（重要！） set PYTHONPATH=%cd% # 验证设置 echo %PYTHONPATH% # 期望输出：E:\DeepHS-Fruit\deephs_fruit
什么是PYTHONPATH？
PYTHONPATH告诉Python："去这个目录找模块"。

为什么需要设置？
训练脚本train.py需要导入utils、models等模块：
from utils.data_loader import load_dataset from models.deephs_net import DeepHSNet
不设置PYTHONPATH，Python找不到这些模块会报错。
注意：
- set PYTHONPATH=%cd%只在当前CMD窗口有效
- 关闭CMD后失效，下次需要重新设置
- 每次新打开CMD窗口都需要重新设置
13 启动模型训练

运行训练脚本，开始训练HS-CNN模型。这是最激动人心的一步！

基础训练命令

python classification/train.py --data_path ./data --model deephs_net --fruit kaki --classification_type ripeness --seed 42 --max_epochs 50 --batch_size 32

参数详解

参数名 说明 可选值/示例
--data_path 数据集根目录路径 ./data 或 E:/DeepHS-Fruit/deephs_fruit/data
--model 使用的模型架构 deephs_net（HS-CNN）
--fruit 训练的水果种类 kaki, mango, avocado, kiwi, papaya
--classification_type 任务类型 ripeness（成熟度分类）, firmness（硬度回归）, sugar（糖度回归）
--seed 随机种子，保证结果可复现 42（任意整数）
--max_epochs 最大训练轮数 50（推荐50-100）
--batch_size 批次大小（每次训练的样本数） 32, 16, 8（根据显存调整）

根据显存调整batch_size

显存大小 推荐batch_size 预计训练时间
4GB 8 30-40分钟
6GB 16 20-30分钟
8GB+ 32 15-25分钟
更多可选参数：
# 使用混合精度训练（节省显存，加速训练） --precision 16-mixed # 强制使用CPU训练（无GPU时） --gpus 0 # 设置学习率 --learning_rate 0.001 # 查看所有参数 python classification/train.py --help

- val_acc长时间不变（可能学习率太小）

常见问题与解决方案

Q1：显存不足（CUDA out of memory）

错误信息：

RuntimeError: CUDA out of memory. Tried to allocate 256.00 MiB (GPU 0; 8.00 GiB total capacity; 7.2 GiB already allocated)

解决方案：

# 方案1：降低batch_size python classification/train.py ... --batch_size 16 # 从32降到16 python classification/train.py ... --batch_size 8 # 如果还不够，降到8 # 方案2：使用混合精度训练（节省显存） python classification/train.py ... --precision 16-mixed # 方案3：关闭其他占用GPU的程序 # 查看GPU使用情况 nvidia-smi # 如果有其他程序占用GPU，关闭它们

Q2：找不到数据文件

错误信息：

FileNotFoundError: [Errno 2] No such file or directory: './data/Kaki'

解决方案：

# 检查数据目录是否存在 dir data\Kaki # 如果不存在，检查data目录位置 dir data # 方案1：使用绝对路径 python classification/train.py --data_path E:/DeepHS-Fruit/deephs_fruit/data ... # 方案2：确认当前目录 cd E:\DeepHS-Fruit\deephs_fruit # 必须在代码根目录 python classification/train.py --data_path ./data ...

Q3：ModuleNotFoundError

错误信息：

ModuleNotFoundError: No module named 'wandb' ModuleNotFoundError: No module named 'spectral'

解决方案：

# 安装缺少的模块 pip install wandb pip install spectral # 一次性安装所有可能缺少的模块 pip install wandb spectral h5py torchmetrics einops

Q4：wandb要求登录

提示信息：

wandb: (1) Create a W&B account wandb: (2) Use an existing W&B account wandb: (3) Don't visualize my results

解决方案：

# 方案1：选择3（不可视化） # 输入：3 # 按回车 # 方案2：禁用wandb（推荐） set WANDB_MODE=disabled python classification/train.py ...

Q5：训练速度很慢

可能原因和解决方案：

问题 检查方法 解决方案
使用CPU而非GPU 查看输出：GPU available: False 重新安装GPU版本PyTorch
batch_size太小 训练参数中--batch_size 4 增大到16或32（如果显存允许）
数据加载慢 每个batch耗时>5秒 增加--num_workers 4参数
GPU未满载 nvidia-smi显示GPU-Util<50% 增大batch_size或检查数据预处理

Q6：训练准确率一直不提升

症状：val_acc停留在0.3-0.4，不再上升

可能原因和解决方案：

# 原因1：学习率太小 python classification/train.py ... --learning_rate 0.01 # 增大学习率 # 原因2：模型未收敛，epoch不够 python classification/train.py ... --max_epochs 100 # 增加训练轮数 # 原因3：数据问题，检查标签 python -c "import pandas as pd; df = pd.read_csv('data/annotations/kaki_labels.csv'); print(df['ripeness_level'].value_counts())"

Q7：Loss变成NaN

错误信息：

Epoch 5: train_loss=nan, val_loss=nan

解决方案：

# 原因1：学习率过大导致梯度爆炸 python classification/train.py ... --learning_rate 0.0001 # 降低学习率 # 原因2：数据中有异常值 # 检查数据范围 python -c "import pandas as pd; df = pd.read_csv('data/annotations/kaki_labels.csv'); print(df.describe())" # 原因3：混合精度训练问题 # 移除 --precision 16-mixed 参数，使用默认精度
