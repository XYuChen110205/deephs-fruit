1. 验证模式 - 文件名标签解析

JavaScript 
function extractTrueLabelFromFilename(filename) {
    const lower = filename.toLowerCase();
    if (lower.includes('unripe') || lower.includes('未成熟')) return 'unripe';
    if (lower.includes('perfect') || lower.includes('完熟')) return 'perfect';
    if (lower.includes('overripe') || lower.includes('过熟')) return 'overripe';
    return null;
}

2. 批量文件配对

JavaScript 
function handleBatchFiles(fileList) {
    const hdrs = {}, bins = {};
    for (let i = 0; i < fileList.length; i++) {
        const f = fileList[i];
        const ext = f.name.split('.').pop().toLowerCase();
        const base = basenameNoExt(f.name);
        if (ext === 'hdr') hdrs[base] = f;
        else if (ext === 'bin' || ext === 'raw') bins[base] = f;
    }
    // 自动配对.hdr和.bin文件
    batchPairs = [];
    allKeys.forEach(key => {
        batchPairs.push({ name: key, hdr: hdrs[key], bin: bins[key] });
    });
}

使用指南

1

切换到批量导入模式

在"输入 · 高光谱图像"区域，点击"批量导入"标签切换到批量检测模式。

2

开启验证模式（可选）

勾选"验证模式"复选框，系统将从文件名解析真实标签用于对比。

✓ sample_unripe_001.hdr 未成熟
✓ batch_perfect_test.hdr 完熟
✓ day01_overripe_03.hdr 过熟
3

上传文件

点击或拖拽.hdr/.bin文件到上传区域，支持多选。系统会自动按文件名配对。

4

开始批量检测

点击"批量检测"按钮，等待检测完成。结果将显示预测正确/错误统计和验证准确率。
